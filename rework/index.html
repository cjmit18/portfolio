Rework

An early C++ and Qt6 desktop prototype for managing employees, training certifications, and shift assignments in a working kitchen.

Source on GitHub All projects
Status
Prototype, in progress
Stack
C++, Qt6 (QML), CMake
Role
Sole developer

The problem

In a production kitchen, the schedule is a puzzle: each workstation needs enough people certified for it, and certifications expire. Rework is meant to track employees, stations, and training records in one place and propose daily assignments instead of working them out by hand.

What is built

  • Data models. C++ classes for employees, stations, and training records.
  • QML front end. A Qt Quick window that calls a C++ backend object to create employee and station records and display their details.
  • Build. CMake with presets, so the project builds the same way on every machine instead of depending on a Visual Studio project file.

Planned

  • SQLite persistence through Qt SQL, with separate UI, service, repository, and database layers.
  • An assignment engine that places certified staff and trainers at each station and flags understaffed stations.
  • Cross-training suggestions for staff closest to a new certification.
  • Automated Windows packaging with windeployqt.

Where it stands

Rework is an early prototype. The repository contains the data models, the QML interface, and the build setup. Persistence, scheduling, and packaging are not implemented yet.
