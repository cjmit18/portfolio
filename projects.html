RPG Game Engine (C++)

A modular game engine built from scratch in C++ with raylib, covering rendering, combat, inventory, AI behavior, and event systems. It uses a tile-based map (Map, Chunk, Tile) with a clean abstraction for querying world data, and pairs data-oriented design with custom Design by Contract macros to catch invalid state early. Scripting and modding support are planned.

C++ · raylib · data-oriented design · Design by Contract
